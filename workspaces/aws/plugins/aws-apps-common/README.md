# AWS Apps Common Plugin

## Overview

The AWS Apps Common plugin provides shared isomorphic code that can be used across both frontend and backend AWS Apps plugins.

## Key Features

- **Shared Types** - Common TypeScript interfaces and type definitions
- **Constants** - Shared constants and configuration values

## Installation

This plugin is not intended to be installed into a Backstage instance directly. It is installed as a dependency of AWS Apps frontend and backend plugins.

- `@alithya-oss/backstage-plugin-aws-apps-backend` - Backend services
- `@alithya-oss/backstage-plugin-aws-apps` - Frontend components
